# CodeAlpha Frontend Development Tasks

This package contains the first two tasks from the CodeAlpha Frontend Development task list.

## Task 1 — Image Gallery

Folder: `CodeAlpha_ImageGallery`

Features:

- Responsive image grid built with HTML and CSS
- JavaScript category filters
- Lightbox image viewer with previous/next navigation
- Keyboard controls: Escape and arrow keys
- Hover effects and smooth transitions

## Task 2 — Calculator

Folder: `CodeAlpha_Calculator`

Features:

- Addition, subtraction, multiplication and division
- Clear, delete, sign toggle and percentage controls
- Live calculation preview with operator precedence
- Keyboard support
- Responsive layout

## Run locally

Open the `index.html` file in either project folder in a browser. The gallery photographs are loaded from Unsplash, so an internet connection is needed to display them.

## Suggested GitHub repository names

- `CodeAlpha_ImageGallery`
